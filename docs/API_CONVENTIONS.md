# Votexa API Conventions & Specifications

## 1. Base URL & Versioning
- **Current Base:** `/api/v1`
- **Protocol:** HTTPS (in production), HTTP (in local dev)
- **Content-Type:** `application/json`

---

## 2. Standard Response Envelope

All API endpoints strictly conform to the unified envelope contract:

### 2.1 Success Response (`2xx`)
```json
{
  "success": true,
  "data": { ... },
  "meta": {
    "page": 1,
    "limit": 20,
    "total": 142,
    "totalPages": 8,
    "hasNext": true,
    "hasPrev": false
  },
  "timestamp": "2026-11-10T10:00:00.000Z",
  "requestId": "req_1710000000_abcde"
}
```

### 2.2 Error Response (`4xx` / `5xx`)
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid input payload provided",
    "details": [
      {
        "field": "startTime",
        "message": "Start time must be in the future",
        "code": "invalid_date"
      }
    ]
  },
  "timestamp": "2026-11-10T10:00:00.000Z",
  "requestId": "req_1710000000_abcde"
}
```

## 3. Headers Convention

| Header | Description | Required | Example |
|---|---|---|---|
| `Authorization` | Bearer token from Supabase Auth or platform JWT | Yes (for protected routes) | `Bearer eyJhbGciOi...` |
| `X-Organization-Id` | Active tenant identifier (UUID) | Yes (for tenant-scoped routes) | `9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d` |
| `X-Request-Id` | Correlation ID for tracing across client & server logs | Optional (generated by server if absent) | `req_1731234567_f9a2d` |
| `Content-Type` | MIME payload type | Required for POST/PUT/PATCH | `application/json` |

## 4. HTTP Status Code Mapping

| Status Code | Code Meaning | Votexa Error Code | Typical Usage |
|---|---|---|---|
| `200 OK` | Standard success | — | Retrieval, updates, idempotent actions |
| `201 Created` | Resource created | — | Creating elections, candidates, organizations |
| `202 Accepted` | Async / scheduled | — | Payout processing, Phase 2 engine stubs |
| `400 Bad Request` | Validation failure | `VALIDATION_ERROR`, `TENANT_CONTEXT_MISSING` | Invalid body or missing tenant header |
| `401 Unauthorized` | Auth required | `UNAUTHORIZED` | Missing or invalid Bearer token |
| `403 Forbidden` | Access denied | `FORBIDDEN` | User lacks role in specified tenant |
| `404 Not Found` | Not found | `ROUTE_NOT_FOUND`, `RESOURCE_NOT_FOUND` | Missing route, election, or user |
| `409 Conflict` | Business conflict | `CONFLICT`, `ALREADY_VOTED` | Duplicate voter code or election slug |
| `429 Too Many Req`| Rate limited | `RATE_LIMITED` | Exceeded request quota window |
| `500 Server Error` | Unexpected fault | `INTERNAL_SERVER_ERROR` | Unhandled runtime exception |

## 5. Standard Module Endpoints (19 Backend Modules)

```
/api/v1/auth
  GET   /me                       # Authenticated user profile and tenant permissions
  POST  /logout                   # Terminate current session

/api/v1/users
  GET   /profile                  # Active profile details
  GET   /                         # List system users (Admin)

/api/v1/organizations
  GET   /                         # List organizations user belongs to
  POST  /                         # Create new tenant organization
  GET   /:id                      # Get organization details

/api/v1/organization-members
  GET   /                         # List members of active tenant
  POST  /invite                   # Invite new member to tenant

/api/v1/elections
  GET   /                         # List elections for tenant
  POST  /                         # Create new election
  GET   /:id                      # Get election details

/api/v1/candidates
  GET   /?electionId=:id          # List candidates for an election
  POST  /                         # Register a candidate

/api/v1/voters
  GET   /?electionId=:id          # List registered voters
  POST  /register                 # Register voter or generate voter code

/api/v1/ballots
  GET   /:electionId              # Get official ballot questions & options

/api/v1/voting
  GET   /status/:electionId       # Voter eligibility & voting phase status
  POST  /cast                     # Cast encrypted ballot with double-voting prevention
  POST  /verify-receipt           # Verify a cryptographic ballot receipt code
  GET   /results/:electionId      # Aggregate election tally and candidate breakdown

/api/v1/packages
  GET   /                         # List available voting SaaS subscription tiers

/api/v1/payments
  GET   /                         # Transaction history for tenant
  POST  /checkout                 # Create Stripe checkout session
  POST  /confirm                  # Confirm payment & post double-entry credit to treasury

/api/v1/wallets
  GET   /my-wallet                # Get tenant balance and pending credits
  GET   /ledger                   # Get immutable double-entry ledger entries

/api/v1/revenue
  GET   /metrics                  # Organization revenue and fee analytics

/api/v1/ledger
  GET   /                         # Double-entry audit ledger entries

/api/v1/refunds
  GET   /                         # List refunds
  POST  /                         # Submit refund request

/api/v1/payouts
  GET   /                         # List organization payout disbursements
  POST  /request                  # Request bank withdrawal

/api/v1/notifications
  GET   /                         # User notifications
  PATCH /:id/read                 # Mark notification read

/api/v1/reports
  GET   /turnout/:electionId      # Election turnout report & analytics

/api/v1/audit
  GET   /                         # Immutable compliance audit log

/api/v1/admin
  GET   /stats                    # Global platform operational metrics
```
